# docs/archive/

## Purpose

This directory contains historical documentation kept for context and reference.
The contents describe completed refactorings, removed or abandoned features, and
superseded approaches.

For current, user-facing documentation, see the parent `docs/` directory.

## File Index

| File | Description |
|------|-------------|
| `MEMORY_SAFETY_ANALYSIS.md` | Historical notes on unsafe `allocate(..., source=...)` patterns and related design exploration |
| `PARSE_DECLARATION_REFACTORING.md` | Historical notes on the `parse_declaration` refactoring and its extracted helpers |
| `README.md` | This directory overview |

## Key Concepts

- Archived documents may not reflect the current codebase and should not be
  treated as implementation requirements.
- When documentation becomes historical, update current READMEs to point to the
  authoritative docs and subsystem READMEs instead.
