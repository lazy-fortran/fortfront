# Examples & Tests Coverage Index

## Policy Snapshot
- Keep canonical inputs under `examples/`; tests must reference those files
  instead of embedding full source snippets.
- The all-examples sweep (`test/integration/test_all_examples.f90`) skips
  focused regressions listed in `examples/skip_all_examples.txt`. Those tests
  already assert exact code generation, so re-running them in the sweep is
  unnecessary duplication.
- When adding a regression or feature demo, record it here and avoid creating
  parallel examples for the same pattern.
- Prefer shared helpers when tests print the emitted source to keep output
  comparison logic DRY.

## Feature Groups
Examples and tests are grouped by the language features they exercise. Use
these lists to spot redundant coverage before adding new files.
